Looking at this 13th-century Middle Dutch charter, I can make out the following transcription:

Ic maec kont hoe dat ic hebbe Werneri van Nazuth vorgud ghedan
allen den dat hant so hant also dat hi mochte sine scraere lant in die stat
van thore allen des gaders die daer so thy fullle jaer jas hoet begien vrlike
enen toe orc sijn coday so well als hy wilt so ghecur up ter herselheyt stroyod
thombe cortogeheit ene sent henst Liechseler vntu jas mit loncheyt londen
simbotse so bunte gesure dat preelden af sundelic ghint thp jhesu dat ghelghe
so doe wellsuy by cie witte cie ende doch so ydaer so jhaer beghen dil
moen vnte gybonden wes daer gheyt die carspaldt sijn coday so wellanc dem
ment so schut wy dat vyslyst sijn coghedo swl twee jedant grodt velimyt janes
bout gitaefs bi shelsen gloerget cit geyde die lusct sijn wy ende ydaer landt
sluyghonde buyf voryheyt geyne vf duebeyt so haeer vratynt naet wellit
vereut men giydt doe ene bert wallit shren jhaer meyffe so schal fult
wallit huec loof wsse die ster walye erue so sine daen die soyceyt
vreeher syonde oy dye velvuere so al sagh freuke so die gulten daer die
blint dyff so stytsden sy allet die sagh worden ghestelet met myeft
vertholt daen den gesaeme wtyng
